# Scripture Seek – Privacy Policy

The privacy policy for **Scripture Seek**, a Bible word search game for Android by PureForm Solutions.

The policy is in [`index.html`](index.html). It's published with GitHub Pages at:

**https://gerald200000.github.io/bibleword-search-privacy/**

Use that link as the privacy policy URL in the Google Play Console.

When the app changes how it handles data (for example, adding analytics or another ad network), update `index.html` and its "Last updated" date.
